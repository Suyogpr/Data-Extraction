#Ekantipur Scraper
**Audio Bee — Data Extraction Intern Assessment**
 
A Playwright-based web scraper that extracts entertainment news and the cartoon of the day from [ekantipur.com](https://ekantipur.com).
 
---
 
## What It Does
 
- Extracts the **top 5 entertainment news articles** from the मनोरञ्जन section with title, image URL, category, and author
- Extracts the **Cartoon of the Day** from the cartoon section with title, image URL, and author
- Saves all extracted data to `output.json` with proper Nepali (Devanagari) text encoding

## Setup
 
### 1. Install uv
 
**macOS/Linux:**
```bash
curl -LsSf https://astral.sh/uv/install.sh | sh
```
 
**Windows (PowerShell):**
```powershell
powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
```
 
### 2. Install dependencies
 
```bash
uv install
```
 
### 3. Install Playwright browser
 
```bash
uv run playwright install chromium
```

## Running the Scraper
 
```bash
uv run python scraper.py
```
 
The browser will open automatically so you can watch it work. Once complete, results are saved to `output.json`.

## How It Works
 
### Entertainment News
The scraper navigates to `ekantipur.com/entertainment` and waits for article cards to load. It scrolls the page slightly to trigger lazy-loaded images, then loops through `div.category` elements extracting the title (`h2 a`), author (`.author-name p a`), image (`.category-image img`), and category (`.category-name p a`) from each card. A `seen_titles` set prevents duplicate articles from being collected.
 
### Cartoon of the Day
The scraper navigates to `ekantipur.com/cartoon` and waits for the page to fully settle. The cartoon section uses a `div.cartoon-wrapper` structure (different from the homepage slider). The title and author are parsed from the `.cartoon-description p` tag which uses a `"Title - Author"` format. If the author is not present, it returns `null`.
 
### Error Handling
All element selectors use safe null checks — if an element is missing, the field returns `null` instead of crashing. The browser is always closed in a `finally` block even if the script fails mid-run.

## Notes
 
- `ensure_ascii=False` is used when writing JSON to preserve Nepali (Devanagari) characters correctly
- The scraper runs in non-headless mode (`headless=False`) so the browser is visible during execution
- The cartoon author may be `null` if the website does not list it on the cartoon page
